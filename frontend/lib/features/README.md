# Reserved Feature Modules

This directory contains placeholder subfolders reserving namespace boundaries for each system module. Each feature folder should follow clean architecture layout rules:

* `/presentation/` - Views, controllers, states.
* `/domain/` - Entity models, use cases, interfaces.
* `/data/` - API providers, network data sources, adapters.
